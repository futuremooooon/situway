# SituWay 배포 패키지

출퇴근 경로와 캘린더 일정에 맞춰 업무 영어를 연습하는 웹앱입니다. 빌드 과정 없는 정적 파일이라 어느 정적 호스팅에 올려도 바로 동작합니다.

## 들어 있는 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (HTML·CSS·JS 한 파일) |
| `config.js` | 배포 설정 (Google OAuth 클라이언트 ID) |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | 홈 화면에 추가(PWA)용 정보와 아이콘 |
| `sw.js` | 오프라인에서도 앱 화면이 열리게 하는 서비스 워커 |

## 배포 방법 (택 1)

- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 주소가 바로 나옵니다.
- **GitHub Pages**: 저장소에 파일을 올리고 Settings → Pages에서 브랜치를 지정합니다.
- **Vercel**: 이 폴더를 새 프로젝트로 가져오고 Framework는 `Other`로 둡니다.

HTTPS 주소에서 열어야 서비스 워커와 Google 로그인이 동작합니다. 로컬 확인은 `python3 -m http.server 8000` 후 http://localhost:8000 으로 엽니다 (파일을 더블클릭해 열면 일부 기능이 꺼집니다).

## 캘린더 연결

배포 환경에서는 두 가지 방법으로 일정을 넣습니다.

1. **.ics 파일 불러오기 (설정 없이 바로 사용)**
   Google 캘린더 → 설정 → 가져오기/내보내기 → 내보내기로 받은 `.ics` 파일을 일정 탭에서 불러옵니다. 앞으로 30일 일정만 읽습니다. 반복 일정은 첫 회차만 읽습니다.
2. **Google 계정으로 가져오기 (OAuth 설정 필요)**
   1. Google Cloud 콘솔에서 프로젝트를 만들고 **Google Calendar API**를 사용 설정합니다.
   2. OAuth 동의 화면을 만들고, 범위에 `.../auth/calendar.events`를 추가합니다. 테스트 단계에서는 테스트 사용자에 본인 계정을 넣습니다.
   3. 사용자 인증 정보 → OAuth 클라이언트 ID → 유형 **웹 애플리케이션**을 만들고, **승인된 JavaScript 원본**에 배포 주소(예: `https://situway.netlify.app`)를 넣습니다.
   4. 발급된 클라이언트 ID를 `config.js`의 `GOOGLE_CLIENT_ID`에 넣고 다시 배포합니다.

   이후 일정 탭의 "일정 가져오기"를 누르면 Google 로그인 창이 뜨고, 앞으로 30일 일정(시작·종료 시각 포함)을 읽습니다. 앱에서 추가한 일정은 기본 캘린더에도 기록할 수 있습니다. 토큰은 브라우저 메모리에만 두고 저장하지 않습니다.

claude.ai 아티팩트에서 열면 위 설정 없이 claude.ai의 Google Calendar 커넥터를 씁니다.

## 캘린더 규칙

일정 탭의 "캘린더 규칙"에서 켜고 끕니다. 전화영어 시간과 추천 과제에 적용됩니다.

| 규칙 | 동작 |
|---|---|
| 회의 시간엔 전화 안 받기 | 정한 전화 시간이 캘린더 일정(앞뒤 여유 0·10·15·30분 포함)과 겹치면 07:00–22:00 중 가장 가까운 빈 시간으로 옮기고, 옮긴 이유를 일정 탭과 학습 탭에 표시 |
| 근무시간엔 전화 안 받기 | 지정한 근무시간(기본 09:00–18:00)과 겹치면 근무시간 밖으로 옮김 |
| 출장·연차 중엔 쉬기 | 종일 일정으로 잡힌 출장·연차 기간엔 전화를 걸지 않음 |
| 출장지 콘텐츠 추천 | 출장·여행 일정 제목에서 나라·도시(싱가포르, 일본, 미국, 영국, 베트남)를 찾아 현지 표현 5개와 팁을 추천 |

## 실시간 승하차 알림

오늘 화면의 "실시간 승하차 알림"에서 실제 대중교통 경로를 찾고, 휴대폰 위치(GPS)로 탈 곳과 내릴 곳을 알려 줍니다.

- 경로 검색은 [ODsay LAB](https://lab.odsay.com) API를 씁니다. 웹 플랫폼 키를 발급받을 때 사이트 주소(예: `https://futuremooooon.github.io`)를 등록하고, `config.js`의 `ODSAY_KEY`에 넣습니다. 키가 없으면 앱에서 직접 입력하거나 "시연 경로로 보기"로 체험할 수 있습니다.
- 안내: 탑승 정류장 250m 전 → 2정거장 전 → 다음 정거장 하차 → 지금 내리세요. 음성 안내와 화면 배너, 안드로이드에서는 진동도 함께 나옵니다.
- 지하처럼 GPS가 약하면 "탔어요"를 누른 시각과 구간 소요시간으로 위치를 추정합니다.
- 웹앱이라 화면이 꺼지거나 다른 앱으로 넘어가면 위치 추적이 멈춥니다. 안내 중에는 화면 꺼짐 방지를 요청합니다.

## 안전 규칙

경로의 도보 구간에는 학습 콘텐츠를 배정하지 않습니다. 도보 구간이 시작되면 재생 중이던 오디오를 멈추고 "주변을 살피며 걸어 주세요" 화면을 보여 주며, 학습 시간 계산에서도 도보 시간을 뺍니다.

## claude.ai 밖에서 달라지는 점

| 기능 | claude.ai | 배포 버전 |
|---|---|---|
| 메일·통화 피드백, 대화 상대 | Claude가 생성 | 규칙 기반 시연 응답 |
| 음성 읽기 | claude.ai 음성 | 브라우저 음성 합성 (기기에 따라 목소리가 다름) |
| 캘린더 | Google Calendar 커넥터 | OAuth 또는 .ics |
| 학습 기록 | 브라우저 저장소 | 브라우저 저장소 (서버 없음) |

AI 응답을 배포 버전에서도 쓰려면 별도 서버에서 모델 API를 호출하는 코드가 필요합니다. 앱의 `askJSON` / `askText` 함수가 그 연결 지점입니다.
